Nested Pages

Turn a command into a submenu: selecting it opens a scoped child list instead of executing. Available from v22.2.0.

Give a command children and it becomes a container. Selecting it pushes a page onto the palette: the query clears, a breadcrumb chip appears, and only that page's commands are searchable. Backspace on an empty input goes back one level. Escape closes the palette from any depth. Try it here: press Cmd+K and pick "Change theme…", "Assign demo issue to…" or "Move demo task to…".

Static Children

Pass an array for a fixed submenu. Children are filtered locally as the user types:

this.palette.register([
  {
    id: 'theme',
    label: 'Change theme…',
    category: 'Preferences',
    pagePlaceholder: 'Pick a theme…',
    children: [
      { id: 'theme.light', label: 'Light', action: () => themeService.set('light') },
      { id: 'theme.dark', label: 'Dark', action: () => themeService.set('dark') },
      { id: 'theme.system', label: 'System', action: () => themeService.set('system') },
    ],
  },
]);

Loaded Children

Pass a function returning an Observable<Command[]> to fetch children when the page opens. The palette shows its loading state while the request is in-flight, then filters the results locally. Results are cached until the palette closes, and popping the page mid-load cancels the request. 

{
  id: 'assign',
  label: 'Assign to…',
  pagePlaceholder: 'Search teammates…',
  pageEmptyMessage: 'Nobody matches that name.',
  children: () => this.userService.getTeamMembers().pipe(
    map(users => users.map(user => ({
      id: `assign.${user.id}`,
      label: user.name,
      action: () => this.issueService.assign(user.id),
    }))),
  ),
}

Children can have children of their own, so multi-step flows come for free. Each level's closures carry the choices made so far: 

{
  id: 'move',
  label: 'Move to project…',
  children: () => projectService.getAll().pipe(
    map(projects => projects.map(project => ({
      id: `move.${project.id}`,
      label: project.name,
      children: () => projectService.getColumns(project.id).pipe(
        map(columns => columns.map(column => ({
          id: `move.${project.id}.${column.id}`,
          label: column.name,
          action: () => taskService.move(project.id, column.id),
        }))),
      ),
    }))),
  ),
}

Provider Children

Point a command at a registered search provider and its page round-trips every keystroke through the provider's search function. If the provider also has a prefix, both entry paths land on the same page: typing @ and selecting "Assign to…" reach the identical search, placeholder, and empty state. 

this.palette.registerProvider({
  id: 'users',
  category: 'People',
  prefix: '@',
  placeholder: 'Search people…',
  search: (query) => this.userService.search(query).pipe(map(toCommands)),
});

this.palette.register([
  {
    id: 'assign',
    label: 'Assign to…',
    children: { provider: 'users' },
  },
]);

Opening a Page Programmatically

openPage() opens the palette straight onto a page, for deep links like a toolbar button. Pass the id of a registered command with children, or a full page object. Only top-level command ids can be resolved this way; nested pages are reached by navigating. 

this.palette.openPage('assign');

Behaviour Notes

Topic Behaviour
Navigation Backspace on an empty input pops one level. Escape closes by default; set escapeBehavior: 'pop' in the config to make it go back one level instead. Closing resets the stack.
Ordering Pages show all children in authored order at an empty query. Fuzzy ranking kicks in once the user types.
Result limits config.maxResults does not apply inside pages; a submenu is always exhaustive. Cap a page explicitly with CommandPage.maxResults via pushPage().
Command ids Child ids must be globally unique. Use a parent.child convention like theme.dark.
Caching Loader results are cached per palette session and refetched after the palette closes. Failed loads are not cached, so re-entering the page retries.
Actions A command with both action and children runs the action first, then opens the page. Useful for analytics or cache priming.
Prefixes Typing a provider sigil inside a page is literal text. Prefix detection only happens at the root.

Parent Command Properties

Property Type Description
children Command[] | (() => Observable<Command[]>) | { provider: string } What the page contains
pagePlaceholder string? Input placeholder while the page is open
pageEmptyMessage string? Message when nothing on the page matches
